CORE MODULES (Activity 2): Daily Mood Tracking, Concern Submission (anonymous option), Wellness Support (hotline), clinic review/reply/status.

ADDED FEATURES
- Wellness Exercises (Help tab): guided, timed Box Breathing, 4-7-8 Breathing, Muscle Relaxation, Neck and Shoulder Stretch,
  Body Scan, Grounding 5-4-3-2-1, Mindful Minute/Pause, Gratitude Journal; progress tracking and a Home suggestion
- Buddies (nickname search, opt-in mood sharing, chat, report), Appointments, Mood calendar, Weekly report (print/PDF)
- Notifications, daily reminder, Need help now button, Stress self-check, clinic Announcements
- Responsive: phone layout (bottom menu) and laptop layout (side menu)

SUGGESTED ROLE DIVISION (6 members)
1. Project Manager / Documentation   2. UI/UX Designer (css/style.css)   3. Login, Sign up, Notifications
4. Mood Tracking, Calendar, Weekly Report   5. Concerns, Appointments, Clinic module   6. Buddies/Chat, Wellness Exercises, Stress check, QA

SCOPE NOTES: The system does not diagnose any condition. No campus professionals' contact list (out of scope in Activity 1).
Buddies, appointments, exercises and other extras are added modules beyond Activity 2; mention them in your write-up.
